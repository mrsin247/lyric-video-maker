No mic. No playing it out loud for the room to hear. You hand it the audio file itself — MP3, WAV, M4A — and it decodes that file right here in the page, listens to the file's own audio data, and writes out the sung words with timestamps. Then you fix anything it misheard, style the vertical preview, and export. Drop in a second song the same way and you can compare the two lyric sheets side by side to check for accidental echoes.

2 Pull lyrics from the file

One button reads your file end to end. It decodes the audio, runs a speech engine (Whisper small.en, running inside this page) over the file's samples, and lands each line in step 3 stamped with the second it's sung. Your file is not uploaded and your mic is never opened.

What happens when you hit the button:
  1. The file is decoded — the browser turns your MP3/WAV into raw audio samples (that's the waveform in step 1) and resamples them to 16 kHz mono, the shape the speech engine eats.
  2. The engine reads the samples — Whisper small.en (transformers.js + ONNX) transcribes the file data itself, one 30-second window at a time, and returns each phrase with the second it starts. Its voice model is encoder 92,324,819 bytes + decoder 156,780,181 bytes + tokenizer/config 3,645,745 bytes = 252,750,745 bytes (252.8 MB) total. The first time you tap the button on a phone it downloads those model files from this site once — use WiFi, about 253 MB — and then your browser keeps them cached, so pulling lyrics works with no internet after that first load. The song file itself never leaves your device. This is the model that won the head-to-head test on real songs: 90.6% and 93.4% of words right, against 32% and 18% for the old Vosk small model it replaces.
  3. Lines land timed — chunks become lines in step 3. Loud backing tracks and heavy effects can still cause mishears — that's what step 3 is for.

The simulated pull uses a built-in demo song whose words are already known, so it shows the exact flow — lines appearing, timed — without needing a file. It is labeled as a simulation wherever it appears.
