# Lyric Video Maker

Drop in a song file (MP3, WAV, or M4A) and it pulls the lyrics out with timestamps, so you can preview them as a vertical lyric video. Fully offline — the Vosk speech model is bundled in, no mic, no upload, no runtime download.

## How to get it on your phone

1. Download `index.html` from this repo (on the file page, use the Raw / Download button, or grab it from Releases).
2. Open `index.html` in your phone's browser.
3. Drop in a song file and let it transcribe. You can fix any misheard lines, style the preview, and compare two songs' lyrics side by side.

## Size

`index.html` is about 60 MB — most of that is the bundled Vosk model (41 MB) and speech engine, inlined so the tool works offline after one download.
